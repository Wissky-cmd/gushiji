# 🐴 黑马记账 (Heima Accounting)

> 一款简洁的桌面记账应用：记录每一笔人民币支出与收入，两级分类管理，月度统计图表，数据本机存储，支持导出备份。
>
> 运行平台：Windows 10/11 ｜ 界面语言：中文 ｜ 数据：本地 SQLite，零服务器、零上传

## ✨ 功能特性

- **记一笔**：收支类型、金额（两位小数）、两级分类、日期、备注
- **账单列表**：按月份查看、按日分组小计、分类筛选、备注搜索
- **编辑与删除**：任意账目可修改删除（删除二次确认）
- **统计报表**：本月支出/收入/结余、分类支出占比饼图、近 12 个月收支趋势图
- **分类管理**：内置 15 大类、61 小类（支出 9 大类 + 收入 6 大类），支持自定义增删改、换图标、调顺序
- **数据导出**：一键导出 CSV 备份（Excel 打开中文不乱码、日期格式原样保留）

## 🛠 技术栈

| 层面 | 技术 |
|---|---|
| 桌面框架 | Electron 39 |
| 界面 | Vue 3 + TypeScript + Vite |
| UI 组件库 | Element Plus |
| 图表 | ECharts |
| 数据库 | SQLite（Electron 内置 node:sqlite，免原生编译） |
| 打包 | electron-builder（NSIS 安装包） |
| 版本管理 | Git |

## 📐 系统设计要点

- **进程架构**：主进程（窗口管理、数据库、文件导出）与渲染进程（界面）分离，preload 脚本经 `contextBridge` 安全暴露 IPC 接口
- **数据设计**：`categories`（两级分类，parent_id 自关联）+ `records`（账目）两张表；金额以"分"为整数单位存储，避免浮点误差；日期列建索引；WAL 模式
- **导出兼容**：CSV 带 BOM 保证 Excel 中文正常；日期列以 `="YYYY-MM-DD"` 文本公式固定格式，防止 Excel 自动改写；捕获文件占用（EBUSY）给出友好提示

## 🚀 安装使用

- **安装包**：Windows 用户直接使用 `dist/` 目录下的 NSIS 安装包（electron-builder 构建，`npm run build:win`）
- **从源码运行**：需 Node.js 20+；`npm install` → `npm run dev`（Windows 也可双击项目根目录「启动APP.bat」）

## 📁 项目结构

```
src/
├── main/        # 主进程：窗口、SQLite 数据库、CSV 导出
├── preload/     # 桥接层：contextBridge 暴露受限 API
├── renderer/    # 界面：Vue 3 页面（账单 / 统计 / 分类管理）
└── shared/      # 主进程与界面共享的类型定义
scripts/         # 图标生成等辅助脚本
```
